# Notes Tracker Plan

## Goal

Create a Notes Tracker application that allows users to:

- Create notes
- View notes
- Update notes
- Delete notes

## Data Model

### Note

- id
- title
- content
- lastModified

## Technical Design

Frontend:
- Angular

Backend:
- Angular In-Memory API

Services:
- NotesService
- LoggingService

Pages:
- Notes List
- Note Form

Testing:
- NotesService tests
- LoggingService tests

## Deliverables

- CRUD functionality
- Logging
- Unit tests
